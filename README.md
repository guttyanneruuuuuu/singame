# Gravity Duel — 重力で戦う3D決闘ゲーム

スマホブラウザで遊べる、軽量・独創的な3Dアクションゲーム。  
**1v1 / 6人個人戦 / 3v3** に対応、**AI戦 / オンライン部屋作成** の両方をサポート。

## 操作（タップ・スワイプ・ドラッグ・ジャイロのみ。仮想スティック無し）

| ジェスチャー | アクション |
|---|---|
| 🫳 **長押し＋ドラッグ → 離す** | ゴム式スリングショット発射（軌道予測ドット表示） |
| ⚡ **タップ** | 自分中心に重力波を放ち相手を吹き飛ばす |
| 💨 **スワイプ** | 短距離ダッシュ回避 |
| 📱 **スマホを傾ける** | アリーナ全体が傾く（独自要素！ 相手を端から落とせる） |

## 独創的な要素

- **アリーナ傾けるジャイロ操作** — 自キャラだけでなく「世界そのもの」を操作
- **軌道予測** — ドラッグ中に着地点プレビュー、技術的なエイミングが可能
- **パワーアップオーブ** — アリーナに浮かぶ3種のオーブ：⚡パルス強化 / 💨ダッシュターボ / 🪨重力ヘビーショット
- **拡張可能なモード設計** — 1v1 / 6人個人戦 / 3v3 を同じコアエンジンで切替

## 部屋でフレンドと対戦

- 「部屋を作る」でホスト → 6文字コード発行 → 招待リンクを共有
- 友達が「部屋に参加」でコード入力、または招待リンクをタップで自動入力
- WebRTC P2P（PeerJSパブリッククラウドのシグナリングを利用）
- ホスト権威モデルで状態同期、約12Hzで位置・スコア・タイルを配信

## 技術スタック

- **Three.js 0.160** — 3Dレンダリング（CDN直読み込み、ビルド不要）
- **WebAudio API** — アセットゼロのプロシージャルSE
- **PeerJS** — WebRTCシグナリング（必要時のみ遅延読込）
- **Vanilla JS modules** — 軽量、依存関係最小

## デザイン

ネオンを避けた **クリーム + クレイオレンジ + ディープオーシャン** のテンペラ画調パレット。

## ローカル起動

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 自動スモークテスト

```
https://<host>/?test=auto&mode=1v1     # または mode=ffa6, mode=3v3
```

コンソールに毎秒スコア・残り時間が出力されます。
